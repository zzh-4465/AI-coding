## 2. 建议积分规则

目标：奖励真实记录和复盘，不以少吃、低消费或连续打卡施压。

| 行为 | 奖励 | 发放条件 |
| --- | --- | --- |
| 记录一笔真实收支 | 每日 +1 | 按账目所属日期计，每天最多一次；手动与 AI 共用额度 |
| 饮食预算达标 | 每日 +1 | 次日首次打开或查看报告时结算；该日有饮食支出、有效正预算，且最终饮食支出不超过该日预算 |
| 完成饮食记录补充 | 每日 +1 | 至少一笔饮食记录填写健康度或感受；不按“健康/不健康”取值区别奖励 |
| 打开应用、互动、创建愿望、内部转账、校准、预算分配 | 0 | 不作为真实记账奖励依据 |

- 单个账目日最多 3 分；连续记录只展示，不额外加分，断签不扣分。
- 今日预算奖励显示“待结算”；不得将当前预算内提前视为整日达标。
- 历史补记可补发记账和记录补充积分；预算奖励仅在存在该日预算依据时补算，不用今天预算替代。
- 删除、修改、改日期后重新核对受影响日期；不再满足条件的奖励应撤销。删后重记只能恢复对应奖励，不能重复累计。
- 撤销时若积分已花掉，不回收形象；差额记入待抵扣，后续成长奖励先抵扣，页面展示原因与金额。
- 成长积分不清零、不兑换现金、不抵扣生活费；形象沿用现有 30/60/80 分档，同一形象只扣一次。
- 测试积分与成长积分分账；999 测试积分仅首次开启赠送，不计入成长、排行榜或本月获得。
- 不追溯重算规则启用前的全部积分。保留旧余额作为迁移期初，标记切换日期；新规则仅处理切换后日期，旧记录仍可修改但不触发补奖。

实现要求：奖励以“规则版本 + 账目日期 + 奖励类型”为唯一键，记录有效/撤销状态与增减流水；兑换关联形象及唯一操作号。重复打开、重试和恢复备份不能再次发奖。迁移同时保存期初余额和待抵扣余额；本地去重不等同于服务端防作弊。

## 3. 统计报告口径

优先完成月报；日统计服务记账与预算判断，周报和跨月趋势后置。

| 指标 | 计算口径 |
| --- | --- |
| 本月真实收入/支出 | 按交易所属月统计外部真实收支；排除池间转账、校准、预算分配、月末结转；外部生活费只计一次来源，分配记录不重复计入 |
| 分池支出 | 真实支出按四池归类，合计须等于总支出；储蓄池的内部划转不算消费 |
| 饮食日均 | 饮食支出 ÷ 有饮食支出的日期数，明确标注“记录日日均”；零记录时显示“暂无记录” |
| 预算达标天数 | 有饮食支出、预算依据且已结算的达标日期数；同时显示可判断天数，不把未记账日算达标 |
| 记录天数/连续记录 | 按账目日期去重，排除内部操作；历史补记不打断最近连续记录，连续记录截至最新有效账目日 |
| 储蓄变化 | 分开列资金池净变动与其中内部转入；不把内部转入同时作为收入或消费 |
| 余额与欠款 | 当月报告列当前余额并标注截至时间；历史月采用月末快照，缺失时显示不可用，不使用当前余额冒充 |
| 成长积分 | 本月发放、撤销、兑换支出分别展示；可用余额和待抵扣单列，测试积分另列 |
| 形象收集 | 展示当前可用总数；只有存在解锁时间记录时才展示“本月新增” |

金额以整数分计算，展示时保留两位小数；所有页面与 AI 输入使用同一统计函数。无记录只表示缺少数据，不推断没有消费；当月标注“进行中”。历史补记或删除后标记报告已变化并重算；若影响月结余额，须同步修订相关月结及后续余额链，不能只改报告数字。

月报顺序：收支概览 → 四池支出 → 饮食预算 → 储蓄与欠款 → 饭团成长 → 至多三条建议。先给数字，再提供可选 AI 解读。

## 4. AI 解读边界

- 默认仅上传必要的本地统计结果、统计口径与数据完整性标记；移除用途名称、商户、愿望标题和原始流水。
- AI 只解释已有指标，不计算资金、不发放积分、不修改账本；缺少预算或历史快照时明确数据不足。
- 网络失败仍能查看完整本地报告；修改账目后标记旧解读失效，用户主动重新生成。
- 报告缓存绑定月份、数据修订号和统计规则版本，防止展示过期结论。

## 5. 实施顺序与验收

| 顺序 | 工作 | 验收重点 |
| --- | --- | --- |
| 1 | 统一真实收支分类与统计函数 | 100 元外部收入分到四池，总收入仍为 100；池间转 20 元不增加收入或支出 |
| 2 | 建立奖励账本、迁移期初和兑换流水 | 同日记多笔最多 3 分；AI 只建愿望 0 分；测试积分与成长积分互不影响 |
| 3 | 结算与修改联动 | 日预算 30 元，先记 10 再记 25：当日预算奖励 0；次日仅结算一次；删除后重记不刷分 |
| 4 | 月报及月末快照 | 补记上月不污染本月；历史余额取对应快照；四池支出可对账，缺数据不补造 |
| 5 | 最小化 AI 输入和失效处理 | 请求不含用途或愿望标题；断网可看本地报告；修改后旧解读标失效 |
| 6 | 扩展周报、跨月趋势与导出 | 复用已验收口径；对比相同长度区间，数据不足不做趋势判断 |

每步完成相应自动验证后再进入下一步；Web/Android 与鸿蒙分别记录构建、自动验证和真机结果。当前仅形成计划，未修改功能、未执行功能测试。
