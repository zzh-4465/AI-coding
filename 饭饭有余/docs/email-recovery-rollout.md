# 邮箱找回与独立备份记录

日期：2026-10-20（北京时间）

## 已实现

- 原账号登录后验证并绑定邮箱；验证前邮箱不能用作登录或找回依据。
- 已验证邮箱可登录原用户 ID；密码重置不更改账本归属。
- 邮件验证码8位、10分钟有效、错误至多5次、一次使用；只保存摘要，接口不返回验证码。
- 发送限额持久化；重置成功撤销全部旧会话及待用验证码。
- 专用 SMTP 发信适配器：465 TLS / 587 STARTTLS，不关闭证书校验。
- 数据库一致性快照先在云端加密，再传回本机；私钥未上传。
